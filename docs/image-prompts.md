## Tips for Gemini

- Generate at the largest size offered, landscape orientation.
- If faces come out odd, add: "faces slightly turned away from camera".
- If it looks too "stock photo", add: "documentary photography style, candid,
  imperfect framing".
- Reject any image with garbled text or extra fingers — regenerate instead.
